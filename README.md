# **Welcome to the 2026:REBUILT Prosper Engineering programming repository**
## Setup:
To set up the code base for running first ensure FRC's version of VSCode installed. You can find *WPIlib* on **First's** official page, which can be found at https://docs.wpilib.org/en/stable/docs/zero-to-robot/step-2/wpilib-setup.html. Once you have WPIlib installed, you can open up the project, and start with a first build **on wifi**. To perform any WPIlib specific commands, you can easily access the shortcuts by clicking the WPIlib logo in the top right of VSCode. Upon clicking on it after the initial gradle build, you can connect to the robot, recieve comms, and click the deploy button to put the code on the robot. This will load code onto the Roborio, which will persist between laptops.
## Modification:
The 2026 codebase was designed to be easy to modify no matter the situation. Most of the code in this repo can be modified through the different constants files, which you can find in their relevant subsystem folders. Making modifications to the code is recommened for setting your ideal tuned PIDF values, motor IDs, and any other customization features you might want to differ from what is currently set.
## For future use:
The `SwerveSetpointGenerator` folder is designed to be moved across projects freely and modified. The job of the swerve setpoint generator is to be given desired robot relative chassis speeds, and return the required module states to reach said goal given all constraints. All IO layers can be freely moved between projects as well as all drive controllers (Assuming the constants are implemented properly for them). Most of the code in the project is easily transferrable across projects, but keep in mind things might need to be changed taking 2027s new **system core** in mind.
